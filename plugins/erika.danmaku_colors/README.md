# 更多弹幕颜色

发送弹幕时，颜色除了白、黑、黄、绿、红、蓝，再多出 NipaPlay 预设里的其余九种：

| 颜色 | 色值 |
|------|------|
| 橙 | `#FF7106` |
| 橙黄 | `#FFAA01` |
| 金黄 | `#FFD301` |
| 黄绿 | `#A0EE02` |
| 青 | `#019899` |
| 天蓝 | `#89D5FF` |
| 玫红 | `#CC0173` |
| 深灰 | `#222222` |
| 灰 | `#9B9B9B` |

## 使用方法

启用后，在播放器里打开发送弹幕的气泡，颜色里就有这九种。

## 权限

- 弹幕修改：给发送弹幕加颜色
