# 弹幕密度图

在画面最下面画一条曲线，画出整集弹幕的疏密，一眼看出哪里最热闹。移植自 NipaPlay 的「弹幕密度曲线」。

整集分成最多 150 段（每段至少 1 秒），数出每段的弹幕，再与前后两段取平均，让曲线平滑一些。数的是正在显示的弹幕：别的插件去掉的、屏蔽词挡住的都不算。换一集或载入新的弹幕时，曲线跟着重画。

## 设置

在播放器的弹幕菜单里：

- **弹幕密度图**：显示或隐藏曲线。
- **密度图颜色**：强调色、红、橙、绿。默认红色，接近 NipaPlay 的默认颜色。颜色跟着系统的浅色或深色外观走。

## 权限

- 播放画面叠加：在画面最下面画这条曲线
