# CRT 滤镜

移植自 NipaPlay 的复古 CRT 显像管后处理滤镜。启用后会在播放器「画质增强 › 画面滤镜」中提供三档效果，并可与任意超分辨率算法同时开启；通过 `//!HOOK OUTPUT` 作用于最终输出画面，视频、字幕与弹幕一同呈现显像管质感。

## 档位

- **轻度**：细腻扫描线与柔和暗角，无屏幕曲面畸变。
- **标准**：适度曲面畸变、扫描线、RGB 三色磷光点阵与暗角。
- **高级**：更强曲面、微色差、柔光泛晕、磷光点阵与轻微噪点。

## 权限

- **画面滤镜**（`picture.filter`）：向播放内核注册 RGB 后处理着色器，不运行脚本、不访问网络。
