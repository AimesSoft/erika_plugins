# 自动弹幕偏移

弹弹play 的弹幕按电视播出的时间轴发送，而网飞（Netflix）的片源在正片前多了片头和一段黑场，弹幕就会早十来秒。打开视频时，这个插件让 Erika 量一下视频开头的 30 秒，认出网飞片头后找到黑场结束、正片开始的时刻，把弹幕延后这么多。

## 怎么认出网飞片头

开头 3 秒内出现黑底红色的 N，并且连续停留 1.5 秒以上，就当作网飞片头。片头之后，第一个大半画面亮起来的时刻是正片，正片从它前面最后一段全黑结束的地方淡入；黑底上一行暗字（「A Netflix Series」）不算正片。

按一部网飞 WEB-DL（《JOJO 的奇妙冒险 飙马野郎》第 5 集）实测：

| 时间 | 画面 |
|------|------|
| 0 – 1.3 秒 | 全黑 |
| 1.3 – 4.96 秒 | 红色的 N 和丝带 |
| 4.96 – 6.1 秒 | 全黑，没有声音 |
| 6.1 – 9.9 秒 | 黑底暗字「A Netflix Series」 |
| 9.9 – 11.6 秒 | 全黑 |
| 11.6 秒起 | 正片淡入 |

30 秒内一直没有画面时，按黑场开始的时刻延后。

## 设置

| 设置 | 说明 |
|------|------|
| 偏移时提示 | 延后弹幕时在屏幕下方提示一下 |

## 说明

- 下一部视频没有网飞片头时，插件会把自己设的偏移改回原来的值；你手动改过的偏移不会被动。
- 目前只有 macOS 版 Erika 能量视频开头，其他平台装了不会偏移。

## 权限

- 弹幕修改：设置弹幕偏移
- 播放器控制：读取视频开头的画面信息
- 界面提示：显示提示
- 存储：记住自己设过的偏移，以便改回
