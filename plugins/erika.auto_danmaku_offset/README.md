# 自动弹幕偏移

弹弹play 的弹幕按电视播出的时间轴发送，而网飞（Netflix）的片源在正片前多了几秒片头，弹幕就会早几秒。打开视频时，这个插件让 Erika 量一下视频开头的几秒，认出网飞片头后把弹幕延后，让弹幕对上正片。

## 怎么认出网飞片头

开头 3 秒内出现黑底红色的 N，并且连续停留 1.5 秒以上，就当作网飞片头。按一部网飞 WEB-DL 实测：1.1 秒前全黑，1.4 秒到 3.4 秒是红色的 N，丝带到 5 秒，5.1 秒又回到黑色。

## 设置

| 设置 | 说明 |
|------|------|
| 网飞片头长度（秒） | 认出片头后弹幕延后多少秒，默认 5，范围 0 到 10；填 0 等于关掉 |
| 偏移时提示 | 延后弹幕时在屏幕下方提示一下 |

## 说明

- 下一部视频没有网飞片头时，插件会把自己设的偏移改回原来的值；你手动改过的偏移不会被动。
- 目前只有 macOS 版 Erika 能量视频开头，其他平台装了不会偏移。

## 权限

- 弹幕修改：设置弹幕偏移
- 播放器控制：读取视频开头的画面信息
- 界面提示：显示提示
- 存储：记住自己设过的偏移，以便改回
