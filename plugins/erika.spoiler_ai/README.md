# AI 防剧透

从 NipaPlay 移植。弹幕载入后，把弹幕文本交给你配置的 AI 服务，识别并屏蔽疑似剧透的弹幕。

> 被分析的弹幕会发到你填写的服务商。识别只是辅助过滤，不保证完全准确；分析大量弹幕会消耗额度和时间。

## 使用方法

1. 在插件设置里填好接口格式、API 地址、API 密钥和模型。
2. 点「测试接口」，用三条示例弹幕请求一次，确认接口能用。
3. 打开「启用防剧透」。之后每次载入弹幕都会分析一遍，命中的弹幕在这个视频里屏蔽。

## 设置

| 设置 | 说明 |
|------|------|
| 接口格式 | `openai`：OpenAI 兼容接口，地址通常以 `/v1/chat/completions` 结尾；`gemini`：Google Gemini，地址可以只填到 `/v1beta/models` |
| API 地址 | 服务商的接口地址 |
| API 密钥 | 只保存在 Erika 里，不要写进截图或公开的问题 |
| 模型 | 默认 `gpt-5` |
| 温度 | 0 到 2，默认 0.5 |
| 调试打印 | 把 AI 的原始回答和命中的弹幕写进日志；排查完请关掉 |

## 说明

- 一次最多分析 1200 条弹幕，请求内容最多约 24000 个字符，超出的部分不分析。
- 命中的弹幕按原文精确屏蔽，只对当前视频生效。

## 权限

- 弹幕修改：屏蔽命中的弹幕
- 网络：请求你配置的 AI 服务
- 界面提示：显示测试结果
